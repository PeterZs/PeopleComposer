# Instruction Prompts

This folder contains the instruction prompts used to construct and evaluate the tiered DrawWaldoWorlds benchmark prompts.

| File | Purpose |
| --- | --- |
| `Structured-Prompt-Expansion-Instruction.txt` | Expands reference images and interaction labels into structured Tier A/B/C prompts. |
| `Prompt-Tiering-Instruction.txt` | Defines the three-tier prompt construction protocol. |
| `Scene-to-Questions-Decomposition-Instruction.txt` | Decomposes multi-person scenes into VQA-style evaluation questions. |
